# Adb-optimizations-for-samsung-phones
Note: DO NOT ADD "ADB SHELL" IN THE CODE WHILE YOU'RE ALREADY IN THE ADB SHELL. UNLESS, THE COMMAND WON'T WORK.
Samsung ADB Optimizer
SSP:
A simple ADB-based optimization tool for Samsung Android devices.

This project includes a batch script to apply a few system settings, along with text files containing the commands and instructions to restore the default settings.

Features

- Adjusts animation speeds
- Includes a command list for manual use
- Provides commands to restore default animation settings
- Does not disable Samsung system apps or remove packages

Files

- "Samsung_ADB_Optimizer.bat" — Runs the optimization commands on Windows
- "Samsung_ADB_Commands.txt" — Contains the optimization commands
- "Samsung_ADB_Restore.txt" — Contains the restore commands
- "README_TR.txt" — Instructions in Turkish

Requirements

- Windows PC
- Android Platform Tools (ADB)
- USB debugging enabled on your phone
- An authorized ADB connection

How to use

1. Download Android Platform Tools.
2. Place the project files in the same folder as "adb.exe".
3. Enable USB debugging on your phone.
4. Connect your phone to the PC and authorize the connection.
5. Run "Samsung_ADB_Optimizer.bat".

Follow the instructions shown in the terminal.

Notes

This project mainly changes animation settings to make the interface feel faster. It does not increase CPU performance or physical RAM.

Compatibility may vary depending on the Samsung device and Android version. Test carefully before using it on your main device.

Disclaimer

Use this tool at your own risk. Always understand the commands before running them and keep a backup of important data.
